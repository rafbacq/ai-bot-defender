Generate a template

One template per category per run. Each page ships with its own category-typed varList (10 Faker canary expressions), applied as a per-site canary_tokens override when you deploy it. Titles and content are checked against the dedup registry so repeat runs never produce the same fake facts.
Generation runs the fine-tuned model (Qwen3-1.7B + LoRA) and can take a few minutes ("All categories" much longer). It needs the template_generator Python environment (torch + transformers + peft); the app runs it with {{ interpreter }} (override via the TEMPLATE_GEN_PYTHON env var).
