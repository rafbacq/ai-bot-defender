Disguised devices — one machine, many identities

Each row is a single physical device (same browser fingerprint) presenting as more than one visitor. Identities basis = it claimed several engines/OSes/client kinds (a browser version update or a second same-engine browser does not count) — that is the disguise, and its requests go red in the table above. Networks basis = one identity seen from several public networks — proxy/VPN rotation, but equally a phone hopping Wi-Fi/LTE, so its requests only go orange. The honeypot serves one device one canary set (via the device cookie fp.js sets), so either way the canary trail stays attributable to this one machine.

Campaign Intelligence

Each row above is a single request. Campaign Intelligence automatically groups those requests into campaigns — clusters of IP addresses that act like one coordinated crawler because they share a device fingerprint, TLS signature, or network — then flags any campaign that's disguising itself as an ordinary browser. It's how undeclared scrapers and agentic AI browsers get caught.
